# 🌐 Web Application Basics — TryHackMe

**Cyber Security 101 | Web Application Security Fundamentals**

## 📌 Project Overview

Completed the **Web Application Basics** room on TryHackMe as part of my cybersecurity learning journey. This practical helped me understand how web applications communicate through HTTP requests and responses, how APIs handle data, and how security controls help protect web applications.

## 🎯 Learning Objectives

* Understand client-server architecture and web application communication.
* Identify URL components: scheme, hostname, path, and query string.
* Analyze HTTP request and response structures.
* Learn HTTP methods: `GET`, `POST`, `OPTIONS`, and `DELETE`.
* Understand HTTP status codes and response headers.
* Explore cookies and security attributes such as `Secure` and `HttpOnly`.
* Learn browser security headers, including CSP, HSTS, and `X-Content-Type-Options`.
* Practice basic API interactions in an authorized lab environment.

## 🛠️ Practical Tasks Performed

| Task              | Description                                                                |
| ----------------- | -------------------------------------------------------------------------- |
| GET Request       | Retrieved user-resource data through an API endpoint.                      |
| POST Request      | Practiced submitting data to modify a user resource.                       |
| DELETE Request    | Explored a request to remove a user resource.                              |
| HTTP Analysis     | Studied request methods, headers, status codes, and responses.             |
| Security Controls | Learned how cookies and browser security headers contribute to protection. |

## 🔐 Key Security Takeaways

* Validate all client-controlled inputs.
* Enforce authentication and authorization on API endpoints.
* Protect sensitive data from unauthorized access.
* Configure appropriate HTTP security headers.
* Use secure cookie attributes and proper session management.
* Review API behavior and response differences during authorized security testing.
